## The entry

One single-line joke excusing a missed deadline, 78 characters, 15 words:

> My boss said the deadline was flexible, so I flexed it right off the calendar.

## How it works

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt`
into `MAKEFUN_OUTPUT_DIR/entry.txt`, so the grader receives exactly the
line that was reviewed, byte for byte. No network, no rendering, no
surprises at grade time.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
